# 印刷套准复核台

接口只把印张偏差放进待处理队列。另一个进程用行锁领走一条，算出套准或套不准后再写回。页面每隔一秒看一次，直到结论出现。

急件可插到领取顺序前面：印刷员投递时勾选「急件」，领取进程先消化全部急件待处理，再碰普通待处理，同一档内按编号从小到大。急件记号在任务创建时写死，之后不随勾选框改动；观察账号看得到急件记号，但勾不了也投不了。「急件车道」页同时展示急件队、普通队以及下一笔将被领走的任务。

```bash
cd projects/15-print-register-review

```

## 验收

1. printer 登录后稍等，封面-01 变成套准，内页-09 变成套不准。
2. 再送一条青偏差 0.5 的印张，状态先是待处理，随后变成套不准。
3. checker 没有送复核按钮。
4. printer 先不勾急件投「样张乙」，再勾急件投「急件样张丙」；急件车道显示下一笔是丙，领取顺序为丙先于乙。
5. 急件队、普通队各自按编号升序；丙的急件记号在总表中只读，之后勾选框复位或再投都不改变它。
6. checker 能进急件车道、看得到 ⚡ 急件记号，但调用投递（即使带 urgent）返回 403。
